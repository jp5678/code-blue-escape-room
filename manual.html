Code Blue : 잠긴 병동 · 사용 설명서

AI융합 간호정보학 학기 종합 복습 방탈출 · 조별(4~5명) 수업 활동

▶ 게임 바로가기
한눈에 보기 시작하기 화면 구성 퍼즐 풀기 결과 제출 구간과 교재 장 교수자 모드 수업 운영 자주 묻는 질문

한눈에 보기

야간 근무 중 7병동 EMR이 사이버 공격 의심으로 잠겼습니다. 712호 김○○ 님(72세 남, 폐렴 입원 3일차)의 상태는 점점 나빠지고, 패혈증 AI 경보(ESM)는 울렸다 꺼지기를 반복합니다. 조원들은 정보간호사 대응팀이 되어 각 공간의 퍼즐을 풀어 시스템을 복구하고, 마지막에 담당의에게 SBAR로 보고하면 탈출합니다.

전체 모드 · 7개 구간 · 제한 45분
프롤로그 + 방 1~5 + 최종 관문
수업 모드 · 5개 구간 · 제한 30분
프롤로그 + 교수자가 고른 방 3개 + 최종 관문
기본 난이도
점수표 등 참고 자료를 보여 줍니다.
심화 난이도
계산·판단 문항이 추가되고 일부 참고 자료가 숨겨집니다.

준비물: 조별 기기 1대(노트북·태블릿 권장, 휴대폰도 가능), 인터넷 연결. 설치나 로그인은 필요 없습니다.

시작하기 (학생)

  1. 교수자가 알려 준 게임 주소로 접속합니다. 수업 모드라면 주소 끝에 ?rooms=…가 붙어 있을 수 있습니다. 그대로 여세요.
  2. 대응팀 등록
    • 반: 드롭다운에서 A~F반 또는 전공심화과정 중 하나를 고릅니다.
    • 조원(학번·성명): 첫 줄(대표 1명)은 필수입니다. 「+ 조원 추가」로 최대 5명까지 넣고, ✕로 지웁니다. 비워 둔 줄은 무시됩니다.
    • 학번은 숫자 7자리(숫자 외 문자는 입력되지 않음), 성명은 한글 또는 영문이며 글자수 제한은 없습니다(영문 이름의 띄어쓰기 가능, 예: Jong Pil Jeong). 같은 학번은 두 번 넣을 수 없습니다.
  3. 모드와 난이도를 교수자 안내에 따라 고릅니다. 아래 「이번 게임에서 열리는 구간」 목록에서 진행할 방을 미리 확인할 수 있습니다.
  4. 🚨 출동 (게임 시작)을 누르면 타이머가 시작됩니다.

이어하기: 진행 상황은 그 기기의 브라우저에 자동 저장됩니다. 창을 닫거나 새로고침해도 시작 화면의 「▶ 이어하기」로 이어서 할 수 있습니다. 창을 닫아 둔 시간은 경과 시간에 들어가지 않습니다.

화면 구성

상단 바
게임 제목, 👥 조 이름·모드·난이도 배지, 남은 시간(힌트·사건 페널티 포함. 제한 시간이 지나면 「초과 시간 +분:초」로 바뀜), 사용한 힌트 수, 🔊 음소거 버튼, 🔄 초기화 버튼(진행 기록이 있을 때만 보임), 맨 오른쪽 📘 사용 설명서 버튼(새 탭). 초기화는 지워질 기록(조·모드·진행 위치·사용 시간)을 확인한 뒤 「초기화」를 직접 입력해야 실행되며, 되돌릴 수 없습니다. 교수자가 정한 수업 모드 방 설정은 지워지지 않습니다.
상단 바 아래 EMR 상태 스트립은 잠김이면 빨간 바탕에 「🔒 EMR 잠김」 배지와 흐르는 빨간 사선 줄무늬로, 복구되면 초록 바탕에 「✓ EMR 가동」과 초록 실선으로 표시됩니다. 여기서 「가동」은 시스템이 작동한다는 뜻이며 환자 상태가 정상이라는 뜻이 아닙니다(환자 상태는 오른쪽 모니터의 NEWS2 점수로 확인). 옆의 NEWS2·ESM 칩으로 어느 시스템이 아직 복구 전인지 확인할 수 있으며, 게임 시작 전에는 잠김으로 표시되고, 방 3-A(NEWS2)와 방 1-A(ESM)를 풀 때마다 해당 칩이 「✓ 가동」으로 바뀝니다. 잠김·끊김 표시는 상단과 모니터 모두 아이콘 둘레에 고리가 퍼지는 같은 방식으로 움직입니다.
업무 화면(왼쪽)
환자 차트 머리줄 · 구간 이름과 교재 장 · 학습목표 · 상황 이야기 · 퍼즐 탭(A, B, C …) · 퍼즐 본문
🖥 중앙 모니터(오른쪽 위)
김○○ 님의 심전도와 활력징후. 시간이 지나거나 오답을 내면 상태가 나빠집니다. 아래쪽 두 표시는 처음에 고장 상태이며, 고장의 종류에 따라 모양이 다릅니다.
· NEWS2(조기경보점수) -- 🔒 계산 모듈 잠김(점수 자리 「--」 = 기능 사용 불가): 방 3-A를 풀면 실시간 점수와 대응 단계가 나옵니다.
· ESM(패혈증 예측 AI) 경보 ⚠ 입력 끊김(빨강 = 신호가 울렸다 꺼지기를 반복). 두 표시는 같은 빨간 경고 색이고 아이콘(🔒·⚠) 둘레에 고리가 1.2초마다 퍼지며, 고장 종류는 문구로 구분합니다: 방 1-A를 풀면 「입력 복구」로 바뀝니다.
수업 모드에서 해당 방이 없으면 처음부터 복구된 상태입니다.
카드 구분
왼쪽 업무 카드는 왼쪽 세로선 색으로 구분됩니다: 버건디(소개·환자 차트), 파랑(대응팀 등록), 금색(퍼즐 탭), 청록(퍼즐), 초록(구간 해제). 오른쪽 중앙 모니터와 병동 현황판은 세로선 없이 살짝 떠 있는 모양으로 강조됩니다.
📋 병동 현황판(오른쪽 아래)
병동 평면도. 해제한 방 ✓, 지금 있는 방은 골드 테두리, 이번 게임에 없는 방은 빗금으로 표시됩니다.

태블릿·휴대폰처럼 화면이 좁으면 모니터와 현황판이 업무 화면 위로 올라갑니다.

퍼즐 풀기

답하는 방법

  • 카드 분류: 카드를 끌어 알맞은 상자에 놓습니다. 태블릿에서는 카드를 누른 뒤 상자 제목을 누르면 옮겨집니다. 모든 카드를 상자에 넣어야 제출됩니다(역할 배정, FHIR, 비식별화, 인력 배치, SBAR).
  • 버튼 선택: 항목마다 한 줄로 놓인 버튼 중 하나를 누릅니다(편향 유형, 개입 시각, 데이터 정제).
  • 순서 맞추기: ▲▼ 버튼이나 끌어서 카드 순서를 바꿉니다(DIKW 피라미드).
  • 선택 상자: 항목마다 목록에서 알맞은 보기를 고릅니다(표준 용어, 규제 원칙, 시나리오 요건).
  • 보기 카드: 「n개 선택」이라고 적힌 문제는 정확히 그 개수만 고릅니다. 「해당하는 것 모두」는 맞는 것을 모두 고릅니다.
  • 숫자·글자 입력: 숫자는 반올림한 정수로(예: 33), 코드는 그대로 입력합니다(예: 1234-5, 하이픈은 있어도 없어도 됨).
  • 그림 자료: 방 1의 흐름도는 연결선을 눌러도 선택되고, 방 5의 코드는 줄을 눌러 고릅니다.
  • 모든 칸을 채운 뒤 제출(또는 Enter)을 누릅니다.

문항과 보기의 순서는 조마다 다르게 섞여 있습니다. 다른 조와 위치를 맞춰 보는 방법은 통하지 않습니다.

정답과 오답

  • 정답이면 디브리핑 카드가 열립니다. 정답 근거, 핵심 개념, 교재 장, 출처(DOI)가 담겨 있으니 조원이 함께 읽고 「계속」을 누르세요. 해결한 퍼즐에서 「📖 디브리핑 다시 보기」로 다시 볼 수 있습니다.
  • 오답이면 「n개 항목 중 m개 정답」처럼 맞은 개수만 알려 줍니다. 오답을 낼 때마다 환자 상태가 나빠집니다.
  • 환자 상태가 끝까지 나빠지면 CODE BLUE가 발생하고 2분 페널티가 붙습니다. 게임은 계속되지만 결과 화면의 「환자 결과」에 반영됩니다.

구역 해제와 단서 카드

한 구역의 퍼즐을 모두 풀면 「🔓 해제!」 화면에 소요 시간과 정답률이 나오고, 방에 따라 🃏 단서 카드를 얻습니다. 단서 카드는 최종 관문의 SBAR 보고에 쓰입니다. 그중에는 보고에 넣으면 안 되는 카드도 섞여 있습니다. 수업 모드에서 하지 않은 방의 카드는 「기본 제공 카드」로 자동 지급됩니다.

결과 확인과 제출

  1. 최종 관문에서 SBAR 보고를 마치면 「AI 공존 시대에 내가 될 간호사」 유형을 고르고 한 줄 다짐을 적습니다. 정답이 없는 문항입니다.
  2. 결과 화면은 환자 결과에 따라 세 가지로 달라집니다: 🏆 「환자를 지켜냈습니다!」(병동 안정화) · ⚠️ 「아슬아슬한 대응」(병동 집중 관찰) · 🚨 「EMR은 복구했지만, 환자는 악화되었습니다」(중환자실 전동). 별점(★ 최대 3개)은 ① 중환자실 전동 없음 ② 제한 시간 안에 완료 ③ 전체 정답률 70% 이상을 하나씩 달성할 때마다 1개씩 받으며, 제한 시간 대비 사용 시간은 막대로 표시됩니다(초과분은 빨간 줄무늬).
  3. 숫자 기록은 ⏱ 시간 · 🎯 정확도 · 💡 도움 세 카드로 묶여 양호/주의/개선 필요로 표시됩니다(정확도 70% 이상 양호·50~69% 주의, 제출 기록이 없으면 「기록 없음」, 힌트 구간당 1회 이하 양호·2회 이하 주의, 시간은 제한 내 양호·20% 이내 초과 주의).
  4. 📈 환자 경과(NEWS2) 그래프는 게임 중 환자 상태를 NEWS2 점수로 바꿔 구간별로 보여 주며, 5점(긴급 평가)·7점(긴급 대응) 기준선, CODE BLUE 발생 시점, 오답(✕)·힌트(◆) 사용 시점(표시를 누르면 그때의 퍼즐, 맞힌 항목 수, 힌트 단계, 환자 NEWS2가 나옴. 정답은 표시하지 않음), 가장 크게 악화된 구간과 오답이 가장 많았던 구간을 표시합니다. 결과 PNG에도 함께 저장됩니다.
  5. 그 아래에 「AI 공존 시대에 우리가 될 간호사」 다짐, 구간별 기록(소요 시간·정답률·힌트), 장별 취약 영역이 나옵니다. 정답률 70% 미만이거나 힌트를 2회 이상 쓴 장은 「⚠ 복습 필요」로 표시됩니다.
  6. 🖼 결과 PNG로 저장을 누르면 반·학번·성명, 환자 결과와 별점, 환자 경과 그래프, 구간·장별 기록이 들어간 이미지가 저장됩니다. 파일 이름은 코드블루_결과_A반_학번_성명외n명.png 형식입니다(조원이 1명이면 「외n명」 없음). 교수자 안내에 따라 이 파일을 제출하세요.

새 게임은 헤더의 「🔄 초기화」로 시작합니다. 초기화하면 이 기기의 결과가 지워지므로 반드시 PNG를 저장한 뒤 누르세요.

교수자 모드

들어가는 방법

  1. 게임 주소 끝에 ?teacher=1을 붙여 엽니다. 수업 모드 주소와 함께 쓸 때는 ?rooms=r1,r3,r4&teacher=1처럼 &로 잇습니다.
  2. 오른쪽 위에 생긴 🎓 교수자 버튼을 누르고 교수자 비밀번호를 입력합니다. 같은 탭에서는 탭을 닫을 때까지 다시 묻지 않습니다.

학생에게는 ?teacher=1이 없는 주소만 나눠 주세요. 비밀번호는 학생에게 알리지 마세요.

자주 묻는 질문

정답을 골랐는데 계속 틀렸다고 나와요.

「n개 선택」 문제에서 개수가 맞는지, 숫자 칸에 반올림한 정수를 넣었는지 확인하세요. 항목이 여러 개인 문제는 그중 일부만 틀려도 오답입니다. 맞은 개수를 보고 나머지를 다시 살펴보세요.

카드가 끌어지지 않아요(태블릿).

카드를 한 번 눌러 고른 뒤(골드 테두리), 옮길 상자의 제목을 누르세요. 다시 누르면 선택이 풀립니다. 잘못 넣은 카드는 「아직 분류하지 않은 카드」 상자로 되돌릴 수 있습니다.

모니터의 「NEWS2 -- 🔒 계산 모듈 잠김」은 고장인가요?

아닙니다. 이야기 설정상 EMR이 잠겨 조기경보점수를 계산하지 못하는 상태입니다. 방 3 간호스테이션의 퍼즐 A를 직접 계산해 풀면 복구되어, 상단 칩이 「NEWS2 ✓ 가동」으로 바뀌고 모니터에 실시간 점수가 나옵니다. 미리 점수를 보여 주면 답이 드러나기 때문에 잠가 두었습니다.

상단의 「✓ EMR 가동」은 환자가 정상이라는 뜻인가요?

아닙니다. 「가동」은 시스템이 작동한다는 뜻입니다. 시스템이 복구되어도 환자는 위험할 수 있으므로, 환자 상태는 오른쪽 모니터의 활력징후와 NEWS2 점수로 판단하세요. 시스템 상태에는 「가동·잠김·끊김·복구」를, 환자 상태에는 「정상·위험」 같은 임상 용어를 씁니다.

새로고침했더니 처음 화면이 나와요.

시작 화면의 「▶ 이어하기」를 누르면 이어집니다. 다른 기기나 시크릿 창에서는 이어할 수 없습니다.

화면이 예전 색이나 예전 내용으로 보여요.

브라우저 캐시 때문입니다. 새로고침(Windows Ctrl+F5, Mac Cmd+Shift+R)을 해 주세요.

소리가 너무 커요 / 안 나요.

상단의 🔊 버튼(또는 M)으로 켜고 끕니다. 브라우저 정책상 화면을 한 번 누른 뒤부터 소리가 납니다. 소리를 켜면(🔇→🔊) 확인음이 바로 울립니다. 확인음이 안 들리면 컴퓨터·브라우저 탭의 음량, iPhone·iPad의 무음 스위치를 확인하고 Ctrl+F5로 새로고침하세요. 「🚨 출동」을 누르면 출동 사이렌이 한 번 울립니다. 문제를 푸는 동안에는 반복 경보가 없고, 정답·오답·구간 해제·환자 악화 때 짧은 효과음만 납니다.

결과 PNG 저장이 안 돼요.

일부 태블릿 브라우저는 다운로드가 막혀 있을 수 있습니다. 이때는 결과 화면을 캡처해 제출하세요.
